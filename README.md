  <h1 style="color: #2c3e50;">Electric Vehicle Data Analysis Project</h1>

  <p style="font-size: 16px; line-height: 1.6;">
    This project involves analyzing a dataset on electric vehicle populations using Python and popular data science libraries like <strong>pandas</strong>, <strong>matplotlib</strong>, and <strong>seaborn</strong>.
    The goal is to perform exploratory data analysis (EDA), handle missing values, and visualize trends in electric vehicle usage.
  </p>

  <h2 style="color: #2980b9;">📁 Project Structure</h2>
  <ul style="font-size: 16px;">
    <li><strong>Electric_Vehicle_Population_Data.csv</strong> – The dataset used for analysis</li>
    <li><strong>pyhtonprojectCA2.py</strong> – Python script for performing data cleaning, EDA, and visualization</li>
    <li><strong>Shivnandanyadavca2.doc</strong> – Project documentation in Word format</li>
  </ul>

  <h2 style="color: #2980b9;">🚀 Features</h2>
  <ul style="font-size: 16px;">
    <li>Loads and displays electric vehicle data</li>
    <li>Checks for null values and cleans up string data</li>
    <li>Plots growth trend of EVs over the years</li>
    <li>Displays top 10 most popular electric vehicle makes</li>
    <li>Uses <strong>matplotlib</strong> and <strong>seaborn</strong> for data visualization</li>
  </ul>

  <h2 style="color: #2980b9;">🛠️ Requirements</h2>
  <ul style="font-size: 16px;">
    <li>Python 3.x</li>
    <li>pandas</li>
    <li>matplotlib</li>
    <li>seaborn</li>
  </ul>

  <h2 style="color: #2980b9;">📌 How to Run</h2>
  <ol style="font-size: 16px;">
    <li>Make sure the CSV file path is correct in the Python script (you may need to update it)</li>
    <li>Install the required libraries using <code>pip install pandas matplotlib seaborn</code></li>
    <li>Run the script using <code>python pyhtonprojectCA2.py</code></li>
  </ol>

  <h2 style="color: #2980b9;">📊 Sample Visualizations</h2>
  <p style="font-size: 16px;">
    The script generates:
    <ul style="font-size: 16px;">
      <li>A line chart showing EV growth trend by model year</li>
      <li>A bar chart showing the top 10 electric vehicle manufacturers</li>
    </ul>
  </p>
